# 图片/图表预览放大功能 — 需求文档

## 概述

预览区中的图片和 Mermaid 图表支持点击放大查看，使用独立遮罩层展示，不影响原页面内容和滚动位置。

## 交互流程

### 打开预览

- 点击预览区中的图片或 Mermaid 图表 → 打开全屏遮罩层

### 预览模式

- 遮罩层浮在所有内容上方，原页面状态完全不变
- 关闭后回到原位置，无重渲染或状态丢失
- 遮罩背景使用半透明深色（如 `rgba(0,0,0,0.85)`），突出图片/图表内容

### 关闭预览

- 点击遮罩空白区域（图片/图表之外）关闭
- 按 Esc 键关闭
- 点击图片/图表本身不关闭，防止误触

### 退出提示

- 预览打开时，顶部显示半透明提示条
- 内容："点击空白区域或按 Esc 退出 · 滚轮缩放 · 拖拽移动"
- 2-3 秒后自动淡出消失

## 缩放与移动

### 滚轮缩放

- 鼠标滚轮向上放大，向下缩小
- 不设放大上限，用户可自由放大查看细节
- 缩小有下限（不小于自适应初始大小）
- 以鼠标指针位置为中心缩放

### 拖拽移动

- 放大后可鼠标拖拽移动查看不同区域
- 拖拽时光标变为 grab/grabbing

## 初始大小策略

- 图片/图表较小 → 放大至屏幕 90%（宽度或高度取较小值，保持比例）
- 图片/图表较大 → 缩小至适合屏幕（max-width: 90vw, max-height: 90vh）
- 确保第一眼就能看清主要内容

## 图片处理

- CSS 缩放，保留原始分辨率
- `image-rendering: auto`（浏览器默认双线性插值，大图清晰）

## Mermaid 图表处理

- 遮罩层中重新渲染 SVG，而非简单放大已有低分辨率输出
- 使用更大的渲染容器，让 Mermaid 生成更高分辨率的图表
- 保留当前主题（深色/浅色）

## 技术方案

- 实现为独立组件（如 `Lightbox.vue`），通过 Preview.vue 控制
- 遮罩层使用 `position: fixed; z-index: 9999` 覆盖整个视口
- 缩放状态和偏移量用组件内 ref 管理
- 监听 wheel / mousedown / mousemove / mouseup 事件实现缩放和拖拽
- Esc 键监听 keydown 事件关闭

## 不做的事

- 不在编辑器区域添加放大功能，仅预览区
- 不支持触屏手势（Pinch to zoom），本应用为桌面端
- 不支持预览模式下的右键菜单操作
