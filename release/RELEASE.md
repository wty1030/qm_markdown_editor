# QMMD Release

## v1.0.0 (2026-05-01)

首个正式发布版本。

### 功能特性
- Markdown 编辑器，支持实时预览
- 10 种 VS Code 风格主题
- 壁纸功能（预设渐变 + 自定义上传）
- Tab 缩进配置（制表符/2/4/8空格）
- 三种视图模式（编辑/预览/分栏）
- 文件树浏览
- 导出 HTML/PDF
- 撤销/重做支持
- iOS 风格应用图标

### 下载
执行 `wails build` 生成可执行文件：
```
wails build
```

生成的文件位于 `build/bin/qmmd.exe`。

### 系统要求
- Windows 10/11
- WebView2 运行时（系统自带或自动安装）
